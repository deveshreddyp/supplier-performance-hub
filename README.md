# Supplier Performance Hub

A Streamlit dashboard that turns supplier contract PDFs and monthly service metrics into searchable supplier scorecards, SLA breach alerts, estimated service credits, renewal reminders, and Excel reports.

> **Synthetic data notice:** ALL data in this repository and application is synthetic and generated for demonstration/testing. Supplier names, contracts, dates, contract values, performance values, and credit estimates are fictional. Do not use for real procurement or legal decisions. This notice is shown in the dashboard footer as well.

## Features
- Eight generated fictional supplier contract PDFs and 12 months of synthetic performance metrics, including intentional breaches.
- Contract extraction with Gemini (`GEMINI_API_KEY`) and schema validation; robust regex fallback when the key is absent or API calls fail.
- SQLite persistence and validation issue log.
- SLA breach analysis, illustrative service-credit estimates, health scores, and 90-day renewal alerts.
- Interactive Streamlit KPI dashboard, trend charts, supplier/date filters, and formatted Excel workbook.

## Requirements
Python 3.11 or newer is recommended. Python 3.11+ is the target; the project also works with compatible newer Python releases.

## Run guide (no Make required)
```bash
python -m venv .venv
# macOS/Linux
source .venv/bin/activate
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
python src/generate_data.py
python src/extract.py
streamlit run app.py
```
The dashboard initializes the SQLite database and validation report when needed. To use Gemini extraction, set `GEMINI_API_KEY` in your environment before running `python src/extract.py`. Never put API keys in source code or commit them. Without a key, the regex extractor is used automatically.

Generate the workbook separately with `python src/report.py`. Run tests with `pytest -q`.

## How it works
1. `generate_data.py` creates fictional PDF contracts and 12 months of supplier performance data.
2. `extract.py` reads PDFs with pdfplumber, requests strict JSON from Gemini when configured, validates the schema, and otherwise extracts known contract patterns with regex.
3. `db.py` loads extracted contracts, SLAs, suppliers, and monthly records into SQLite.
4. `validate.py` checks source data and stores issues in `validation_report`.
5. `analyze.py` compares actual monthly metrics to contractual thresholds, flags breaches, estimates uptime credits, calculates health scores, and finds upcoming renewals.
6. `app.py` presents the dashboard; `report.py` exports Scorecards, Breaches, Renewals, and Validation Issues to Excel.

## Architecture
```text
Synthetic PDF contracts ──> pdfplumber ──> Gemini (optional) / regex fallback
                                                │
Synthetic performance.csv ──────────────────────┤
                                                v
                                    JSON schema validation
                                                v
                                      SQLite (sqlite3)
                                      /      |      \\
                               validation  analysis  renewal logic
                                                |
                                   Streamlit + Plotly dashboard
                                                |
                                    openpyxl Excel report
```

## Excel report
`reports/supplier_report.xlsx` contains four sheets: **Scorecards**, **Breaches**, **Renewals**, and **Validation Issues**. It is generated on demand and offered as a dashboard download.

## Notes
- Service credits are illustrative estimates based on the synthetic sample contract language; they are not a legal interpretation.
- Gemini API usage may incur charges and is optional. The app remains usable without a key or network access.
- SQLite database and generated report are local artifacts; PDF contracts and performance CSV are generated by the data script.
